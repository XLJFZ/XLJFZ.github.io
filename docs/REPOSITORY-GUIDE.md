# 仓库导航与文件归档

## 日常修改入口

| 内容                 | 位置                          | 约定                                           |
| -------------------- | ----------------------------- | ---------------------------------------------- |
| 页面与路由           | `src/app/`                    | 每个工具的入口在 `tools/<slug>/page.tsx`       |
| 页面组件             | `src/components/`             | 页头、页脚、画廊与工具界面在此复用             |
| 基础组件             | `src/components/ui/`          | 只保留实际使用的组件                           |
| 逻辑与作品数据       | `src/lib/`                    | 作品顺序、说明和 EXIF 只改 `portfolio.ts`      |
| 公开资源             | `public/`                     | 所有文件均可能随站点公开；只放经确认的展示资源 |
| 可重复使用的维护脚本 | `scripts/`                    | 从仓库根目录执行                               |
| 自动检查与测试样本   | `tests/`                      | 样本放 `tests/fixtures/`                       |
| 维护说明             | `docs/`                       | 从[文档导航](README.md)进入                    |
| 发布流程             | `.github/workflows/pages.yml` | GitHub Pages 的实际配置                        |

现有源码已经按页面、组件、逻辑分层。增加文件时沿用这些位置；框架、格式化和包管理配置保留在根目录。

## 脚本用途

| 命令或脚本                               | 用途                                                       |
| ---------------------------------------- | ---------------------------------------------------------- |
| `npm run dev`                            | 本地开发                                                   |
| `npm run build`                          | 构建应用                                                   |
| `npm run export:github-pages`            | 生成 `_site/` 静态发布目录                                 |
| `npm run check:assets`                   | 检查源站公开图片；加 `-- --export` 检查导出产物            |
| `npm run previews`                       | 从仓库外原图生成画廊预览，需设置 `PORTFOLIO_ORIGINALS_DIR` |
| `npm run favicon`                        | 生成站点图标                                               |
| `node scripts/generate-exif-fixture.mjs` | 维护 EXIF 测试样本                                         |
| `npm test` / `npm run lint`              | 自动测试与静态检查                                         |
| `npm run format -- --check`              | 只检查格式；不带 `--check` 会改写文件                      |

完整提交与发布要求以[维护规范](SITE-GUIDELINES.md#10-必须通过的质量检查)为准。

## 本地生成内容

以下目录已由 `.gitignore` 排除，不属于源码，也不能作为公开资源目录使用。

| 位置                               | 内容与处理方式                                                 |
| ---------------------------------- | -------------------------------------------------------------- |
| `node_modules/`                    | 安装的依赖                                                     |
| `dist/`、`_site/`                  | 构建与静态导出结果                                             |
| `.next/`、`.vinext/`、`.wrangler/` | 框架与运行缓存                                                 |
| `outputs/<日期>-<任务>/`           | 新任务的截图、日志、一次性检查脚本                             |
| `outputs/archive/2026-09-22/`      | 本次归档的历史零散文件；附原路径与 SHA-256 清单                |
| `outputs/preview-generation-*/`    | 预览生成暂存与旧预览备份；可能包含唯一恢复副本，不能当缓存清空 |

新任务请直接建立独立输出子目录，避免把文件散放在根目录或 `outputs/` 顶层。一次性脚本可能依赖执行时的工作目录，归档后仅作历史参考；确认仍需复用后再整理为 `scripts/` 下的正式脚本。

原图保留在仓库外，具体位置由 `PORTFOLIO_ORIGINALS_DIR` 指定；不要迁入 `public/`。本地备份、历史截图与照片来源文件应保留来源信息，确认用途前不删除。此次整理没有改动仓库外的照片和备份。
